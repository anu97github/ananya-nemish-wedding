# Ananya & Nemish — Cinematic Wedding Invitation

A responsive, multi-section wedding invitation for **2–3 February 2027** at **Happy Retreats – KAI**, Agalagurki, Chikkaballapur, Karnataka.

## Project files
- `index.html` — invitation structure and event details
- `styles.css` — responsive editorial styling, transitions and motion
- `script.js` — opening sequence, scroll reveals, countdown, navigation and original ambient score
- `assets/hero-garden.svg` — original vector illustration for the hero scene

## Experience
- Animated envelope opening and cinematic invitation reveal
- Responsive navigation and scroll-triggered chapter reveals
- Countdown to the first celebration
- Event timelines, family acknowledgements and dress colour palettes
- Supplied Google Maps pin plus a full-address directions fallback
- Optional original ambient score generated in-browser using the Web Audio API; it starts only after a guest taps the sound control

## Run locally
Open `index.html` in a browser or serve the directory with any static web server. There is no build step. Google Fonts load when online.

## RSVP and guestbook
The visual RSVP area is in place, but Google Sheets-backed RSVP collection and the moderated guestbook are not connected yet. Those need a separate backend integration before guests can submit and store responses.
